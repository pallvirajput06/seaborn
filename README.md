# 📊 Seaborn Practice 

A collection of Seaborn examples and visualizations created while learning Data Visualization using Python.

## 📌 About

This repository contains practice notebooks and Python scripts demonstrating how to create informative and attractive visualizations using the **Seaborn** library. The goal is to understand different plot types and improve data analysis skills through visualization.

## 🚀 Topics Covered

* Introduction to Seaborn
* Line Plot
* Scatter Plot
* Bar Plot
* Count Plot
* Histogram
* KDE (Kernel Density Estimation) Plot
* Box Plot
* Violin Plot
* Strip Plot
* Swarm Plot
* Pair Plot
* Heatmap
* Joint Plot
* Regression Plot (regplot & lmplot)
* Distribution Plot
* Customizing Themes and Styles
* Color Palettes
* Figure Size and Labels
* Working with Real-world Datasets

## 🛠️ Technologies Used

* Python 3
* Seaborn
* Matplotlib
* NumPy
* Pandas
* Jupyter Notebook

## ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/Seaborn-Practice.git
```

Move into the project directory:

```bash
cd Seaborn-Practice
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
